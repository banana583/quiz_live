# Quiz Live MVP

Веб-приложение для создания и проведения квизов в реальном времени.

Проект реализован в виде npm workspaces-монорепозитория и состоит из клиентского приложения, REST API, Socket.IO-сервера и базы данных PostgreSQL.

Ссылка на макеты https://www.figma.com/design/G4YbIA2M1GvMFq8TQhPPnw/Quiz-Live?node-id=0-1&t=Po16KKT9lpXXUMVz-1
Ссылка на репозиторий https://github.com/banana583/quiz_live

## Возможности

### Для организатора

- регистрация и авторизация с ролью организатора;
- создание, редактирование и удаление квизов;
- выбор категории и добавление описания;
- настройка общего времени на вопрос от 5 до 300 секунд;
- настройка количества баллов отдельно для каждого вопроса;
- добавление вопросов с одним или несколькими правильными ответами;
- добавление изображения по URL или загрузка с устройства;
- создание игровой комнаты с шестизначным кодом;
- запуск квиза и переход между вопросами;
- просмотр количества подключённых участников и отправленных ответов;
- просмотр текущего и итогового лидерборда;
- просмотр истории запусков.

### Для участника

- регистрация и авторизация с ролью участника;
- подключение к комнате по шестизначному коду;
- ответы на вопросы в пределах установленного времени;
- выбор одного или нескольких вариантов ответа;
- получение информации о правильности ответа и начисленных баллах;
- просмотр итогового лидерборда;
- просмотр истории участия для авторизованного пользователя;
- повторное подключение к текущей игровой сессии после обновления страницы.

## Переменные окружения

Из корневой папки проекта создайте два файла на основе `.env.example`:

```bash
cp .env.example .env
cp .env.example apps/server/.env
```

Корневой `.env` используется командами Prisma, а `apps/server/.env` загружается серверным приложением при запуске.

Содержимое файлов:

```env
DATABASE_URL="postgresql://quiz:quiz@localhost:5433/quiz?schema=public"
JWT_SECRET="replace-with-a-long-random-secret"
SERVER_PORT=4000
WEB_ORIGIN="http://localhost:3000"
NEXT_PUBLIC_API_URL="http://localhost:4000"
NEXT_PUBLIC_SOCKET_URL="http://localhost:4000"
```

Перед использованием замените `JWT_SECRET` на собственную длинную случайную строку.

При стандартном локальном запуске клиент использует адреса `http://localhost:3000` и `http://localhost:4000` по умолчанию.

## Запуск проекта

Все команды выполняются из корневой папки проекта.

### 1. Запустить PostgreSQL

```bash
docker compose up -d
```

Контейнер PostgreSQL будет доступен на локальном порту `5433`.

### 2. Установить зависимости

```bash
npm install
```

### 3. Сгенерировать Prisma Client

```bash
npm run db:generate
```

### 4. Применить миграции

```bash
npm run db:migrate
```

### 5. Добавить демонстрационные данные

```bash
npm run db:seed
```

### 6. Запустить клиентскую и серверную части

```bash
npm run dev
```

После запуска доступны:

- веб-приложение: `http://localhost:3000`;
- проверка работы сервера: `http://localhost:4000/health`.

## Остановка PostgreSQL

Остановить контейнер:

```bash
docker compose down
```

Остановить контейнер и удалить локальные данные базы:

```bash
docker compose down -v
```

Команда с параметром `-v` удаляет Docker volume с данными PostgreSQL.

## Особенности MVP

- изображения сохраняются в виде URL или Data URL в базе данных;
- история участия привязывается к аккаунту только у авторизованного участника;
- игровые данные и проверка ответов обрабатываются сервером;
- для обмена событиями в реальном времени используется один экземпляр Socket.IO-сервера.
